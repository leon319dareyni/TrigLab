# 🧪 TrigLab

An interactive trigonometry laboratory built with Python.

TrigLab combines mathematical calculations, scientific
visualization, automated testing, and an interactive web
interface in one educational project.

## Features

- Trigonometric calculator
- Degree and radian conversion
- Inverse trigonometric functions
- Right-triangle solver
- Interactive unit-circle visualization
- Sine, cosine, and tangent plotting
- Randomized trigonometry quiz
- Automated mathematical tests

## Technologies

- Python 3.11+
- NumPy
- Matplotlib
- Streamlit
- pytest

## Installation

Clone the repository:

    git clone https://github.com/leon319dareyni/TrigLab/
    cd TrigLab

Create a virtual environment:

    python -m venv .venv

Activate it on Linux:

    source .venv/bin/activate

Activate it on Windows PowerShell:

    .venv\Scripts\Activate.ps1

Install dependencies:

    python -m pip install -r requirements.txt

## Run the application

    streamlit run app.py

Streamlit will provide a local URL where you can use
the interactive application in your browser.

## Run the tests

    python -m pytest -v

## Mathematical concepts

TrigLab explores:

- Degrees and radians
- Sine, cosine, and tangent
- Inverse trigonometric functions
- Right triangles and the Pythagorean theorem
- The unit circle
- Periodic functions and discontinuities
- Floating-point precision

## Project structure

- `triglab/`: Mathematical logic and visualization
- `tests/`: Automated tests
- `app.py`: Interactive web interface

## Learning objectives

This project is designed to practice Python programming,
modular software design, numerical computing, data
visualization, error handling, testing, and Git.
